# Win11 Theme for Hyprland

## 👋 FIRST OF ALL, HELLO!

Hello everyone! :D

This is my **Windows 11 inspired theme for Hyprland**.

The project is mainly based on **Waybar, EWW, MPVPaper and Pywal**.
